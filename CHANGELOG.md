# История изменений

## 2026-10-06 — постпроцессирование V1.38

- В окне выбора места вывода добавлена кнопка «Папки со станками…»: локальные и сетевые пути, добавление нескольких корней, изменение названий и удаление записей. Поддерживаются выбор через диалог и вставка пути, включая кавычки Windows «Копировать как путь».
- Изменения сохраняются в `[MachineRoots]` существующего INI только по кнопке «Сохранить». Другие разделы, пути постов, комментарии, кодировка и окончания строк сохраняются. Отмена ничего не записывает, удаление записи не удаляет каталоги или программы.
- После сохранения список кнопок станков обновляется сразу, размер окна пересчитывается; место вывода выбирается заново. Настройки BIN, нумерации, имён УП, привязок и ручной папки сохранены. Правило поиска прежнее: непосредственные подпапки с названиями из цифр и отдельные записи `[Machines]`.
- Недоступный новый путь, отсутствие пронумерованных подпапок, неверные названия или конфликт изменения INI блокируют сохранение. Неизменённые недоступные корни можно оставить; их состояние показывается в предупреждении. Дополнительные служебные файлы не создаются.
- Проверены компиляция C# 7.3 с моделями NX API, сохранение настроек в UTF-8/UTF-16, отмена, несколько корней, обновление списка и выбор нового станка, ошибки доступа и конфликт записи. Новое окно и сетевой доступ ещё нужно проверить в целевой NX / Designcenter. Обновлены manifest, README и руководства.

- Последовательно отменяются текст и привязки, параметры стрелок и масштаба, ширина и видимость столбцов, перенос операций, изменения ячеек, изображений и вида модели. Перетаскивание и движение ползунка объединяются в один шаг.
- Удалённые исходные виды и вставленные картинки восстанавливаются с сеткой, размерами, масштабом, сдвигом и вариантом IPW / NO IPW. Данные истории хранятся в памяти, без дополнительных файлов и копирования геометрии модели на каждом шаге.

- Проверены действия редактора, удаление и восстановление изображений, текстовый Ctrl+Z, модель, сохранение/открытие и печать в Chromium, реальное автосохранение и проверки репозитория Windows/Linux. Запуск в целевой NX / Designcenter остаётся необходимым.

## 2026-10-06 — постпроцессирование V1.37

- В первое окно выбора программ добавлена галочка «Нумеровать операции», снятая при каждом запуске. Без неё сохраняются исходные имена операций, включая прежние номера; дополнительная отметка отмены NX не создаётся. Выбор действует для обычного вывода и выбранных операций и не записывается в INI.
- При включении галочки названия операций в дереве NX получают префиксы `1_`, `2_`, … по порядку дерева, с новой нумерацией в каждой выводимой УП. Прежние начальные номера заменяются; в режиме выбранных операций переименовываются только выбранные.
- Отмена или ошибка до сохранения первой УП восстанавливает исходные имена. Успешное или частичное сохранение оставляет новые имена и отметку отмены NX. Обработка NC-кода, пути вывода, привязки и BIN сохранены.
- В меню выбора поста добавлена кнопка «Пути к постпроцессорам»: названия, добавление и удаление записей, выбор TCL/DEF с автоматической подстановкой одноимённого DEF. Настройка доступна при общем посте и при назначении постов отдельным УП.
- Изменения постов записываются в основной INI только по кнопке «Сохранить», затем список обновляется. Прочие параметры, комментарии, кодировка и окончания строк сохраняются. Отмена не записывает изменения, удаление записи не удаляет файлы поста; при отсутствии INI его создаёт первое сохранение.
- Проверены компиляция C# 7.3 с моделями NX API, оба состояния галочки, сохранение имён при отключённой нумерации, повторная нумерация и откат, настройка постов, INI и вывод через разные посты. Запуск новой редакции в целевой NX / Designcenter ещё требуется. Обновлены manifest и руководства; рабочее имя файла сохранено.

## 2026-10-05 — Zmin V1.02

- Исправлена причина неверного Z при повороте детали: формат траектории `Three` может содержать наклонённый `ToolAxis`, который V1.01 заменяла осью Z системы MCS. Теперь фактический вектор движения используется и для `Three`, и для `Five`.
- Начало MCS должно лежать на оси вращения детали. При совпадении оси инструмента с Z системы MCS результат обычной трёхосевой обработки сохраняется. Недоступная ось и дуги или винтовые движения с изменением оси приводят к пропуску операции с объяснением.
- Пройдены 25 тестов вне NX; проверены 8 346 сохранённых CL-точек из 35 операций и воспроизведены 17 полных траекторий, включая дуги и винтовые движения. Контрольный запуск новой версии в NX ещё требуется.
- Обновлены версия и SHA-256 в каталоге апдейтера, README и инструкция Zmin. Рабочее имя файла сохранено.

## 2026-10-05 — апдейтер V1.10

- Исправлена найденная Windows CI ошибка `WinError 5` при замене существующего скрипта или INI самого апдейтера: собственный защитный дескриптор закрывается непосредственно перед атомарной заменой текущего файла.
- Сохранены проверка контрольных сумм перед записью, защита остальных файлов во время подготовки и откат при обычной ошибке. Тест отката теперь проверяет, что первая замена действительно выполнена перед имитацией сбоя второй.
- Минимальная версия каталога повышена до V1.10. С V1.08 и V1.09 требуется однократно заменить апдейтер вручную, сохранив личный INI.

## 2026-10-05 — первый публичный комплект GitHub

Опубликованы 13 журналов для CAM, карт наладки, чертежей, экспорта и управления файлами. Рабочие имена постоянны; версия указана внутри каждого исходника.

### Апдейтер V1.09

- GitHub: один `manifest.json` при проверке, скачивание выбранных исходников при установке.
- Проверка схемы, путей, SHA-256 и внутренних версий; запрет понижения версии.
- Существующий интерфейс выбора и рабочие пути сохранены. Режим папки доступен вручную; автоматического перехода на другой источник при ошибке нет.
- Пользовательские INI и реестр нумерации не обновляются вместе со скриптами. Примеры создаются только при установке отсутствующего скрипта и отсутствующих настроек.
- Запись через соседний проверенный файл с атомарной заменой; откат из памяти при обычной ошибке. Временные `.pending` убираются после операции, остатки завершённого процесса — при следующем запуске.
- Самообновление после закрытия окна и завершения потоков. Переход с V1.08 требует однократной ручной замены апдейтера.
- Защита от второго окна в том же сеансе Windows. Кнопки и New User Command не создаются.
- Добавлены тесты сохранности данных и CI для Linux/Windows. Они не заменяют проверку NX и Win32-окна.

### Карта наладки V2.37

- Блок примечаний растёт по высоте без уменьшения шрифта и растягивается за нижнюю границу; высота сохраняется в карте.

- Карта включает Zmin траектории в MCS операции.

### Минимальный Z в именах операций V1.01

- В V1.01 обнаружен неверный расчёт Z для части траекторий при повороте детали; причина исправлена в V1.02.
- Добавлено переименование выбранных операций либо всех операций проекта при пустом выделении.
- Конечный суффикс `_Zчисло` добавляется или заменяется; для четырёхосевых траекторий Z пересчитывается по текущему направлению инструмента. Начало MCS должно лежать на оси вращения детали.
- Сохраняются проверки траекторий и конфликтов имён, отмена в NX; отдельные настройки и служебные файлы не создаются.

### ЕСКД V1.35

- Из публичного исходника удалены байты стороннего шрифта ASCON, разрешение на распространение которого не установлено.
- Загружается внешняя разрешённая пользователю копия той же редакции из папки скрипта или предусмотренных каталогов NX/Windows.
- Проверка размера, CRC и фактически подключённого семейства сохранена. Похожий шрифт автоматически не подставляется. Без совместимого файла оформление не запускается.
