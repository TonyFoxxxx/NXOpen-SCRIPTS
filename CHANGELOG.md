## 2026-11-16 — Зеркальная копия CAM-проекта, тест V1.30.09

V1.30.08 остановилась до карты на 821049 — Tag limit would be exceeded — при точном габарите, после успешного первого локального возврата из истории. Общий Undo и закрытие копии затем завершились ошибками; успешное восстановление сеанса не подтверждено. Дополнительных ошибок карты/аудита собрано 0. Убран только повтор полного контроля между уже проверенным Undo и следующим историческим контекстом; проверки после каждого Stop/Undo сохранены. Код 821049 останавливает дальнейшую диагностику/создание объектов, оставляя попытки собственного закрытия/отката. Отчёт показывает объект, CSYS и номер вызова габарита, сохраняет первичную ошибку при сбое WCS и различает возврат команды Undo от непроверенной целостности модели.

Добавлены 20 регрессий; всего 835 профильных проверок вне NX, включая прежние 147 с C-фикстурами. Причина исчерпания тегов и устранение ошибки в DC 2606 не подтверждены; следующий тест только в новом сеансе NX из исходного PRT с диска. Блокировки неизвестного ребра и коллекции Part Box, запрет Commit исторической карты и обязательный откат сохранены. Версия, SHA-256, README и руководства RU/EN согласованы. [Результат и текущий этап](docs/mirror-project.md#resource-failure-v13009).
