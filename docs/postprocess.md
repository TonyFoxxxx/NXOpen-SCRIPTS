# Постпроцессирование и вывод на станок

Скрипт: [NX_Postprocess_To_Machine.cs](../scripts/NX_Postprocess_To_Machine.cs). [Все скрипты](../README.md#скрипты).

Выводит выбранные CAM-программы через назначенные постпроцессоры, сохраняет отдельные УП и при необходимости контейнер FANUCPRG.BIN.

## Выбор программ и постов

- Показывает папки в порядке дерева Program Order с вложенностью. Галочка родителя выбирает ветку; непосредственно выводятся программы с латинской заглавной O в начале имени.
- Вложенные O-программы выводятся отдельно, без повторного включения их операций в родительскую программу.
- Кнопка «Вывести УП для выбранных операций» использует только операции, выделенные в NX перед запуском. Для полученных программ можно задать O-номера.
- Можно выбрать общий пост для всех программ либо назначить свой пост каждой УП через «Разбить по разным постпроцессорам».
- Поиск поста работает по названию и пути. «Открыть INI» и «Обновить» позволяют изменить и перечитать конфигурацию.
- Список постов формируется из INI и, при соответствующей настройке, стандартного списка NX.

## Проверки перед выводом

- Сопоставляются диаметры, распознанные в названиях инструментов, с фактическими настройками инструментов всего CAM-проекта, включая неиспользуемые.
- Проверяется MCS операций каждой выводимой программы. Смешанная или недоступная MCS показывается в отдельном предупреждении.
- При проблемах с диаметрами или MCS продолжение возможно только через явный выбор пользователя; настройки инструментов и MCS при этом не исправляются.
- Проверяются файлы постов, имена результатов, повторяющиеся пути, доступность папки и выбранного внешнего носителя.
- Все программы сначала подготавливаются и проверяются. Неожиданные дополнительные выходные файлы поста блокируют публикацию результатов.

## Параметры результата

- Выбор папки станка из INI, произвольной локальной или сетевой папки либо внешнего носителя. Поиск носителей выполняется по отдельной кнопке.
- Необязательное сохранение второй копии УП и BIN рядом с исходным PRT.
- Ручное назначение номера каждой УП: буква O добавляется автоматически, вводятся 1–8 цифр, номер 0 запрещён. Меняются имя файла и O-заголовок в коде; названия папок NX сохраняются.
- Расширение определяется назначенным постом и настройками конфигурации.
- Вывод начинается по кнопке «Вывести». Для замены существующих результатов требуется подтверждение.

## Вызов подпрограмм

В окне «Вызов подпрограмм» можно включить вызов остальных выбранных программ из первой и изменить порядок мышью или кнопками.

Главная УП последовательно вызывает остальные через M98 и завершается M30. Остальные УП завершаются M99. Для этого режима поддерживаются номера O1–O9999; формат вызова более длинных номеров зависит от стойки и здесь не выбирается автоматически.

## Обработка по нескольким привязкам

«Обработка по привязкам» задаёт список от одной до шести разных привязок: 1 = G54, …, 6 = G59. Их можно добавлять, удалять и переставлять. Для каждой выбранной УП обработка одного инструмента повторяется по всему списку, затем начинается следующий инструмент. MCS в NX не меняется.

Режим рассчитан на поддерживаемый трёхосевой числовой ISO-код с M06 и отводом G91 G28 Z0. Неподдерживаемые команды, макросы, выражения и неоднозначные состояния блокируют вывод пакета. Это не универсальное преобразование произвольной станочной программы.

## FANUCPRG.BIN

- BIN можно отключить, сохраняя только отдельные УП.
- «Добавить / обновить» сохраняет прочие программы существующего контейнера и заменяет совпавшие O-номера.
- «Новый BIN» создаёт контейнер только из выбранных УП.
- Выбирается ёмкость 2, 4, 8 МБ или свой размер. Полный размер файла показывается в окне; при переполнении автоматического увеличения нет.
- При нескольких местах сохранения каждый существующий BIN обрабатывается отдельно.

## Как пользоваться

1. Откройте CAM-проект с подготовленными траекториями. Если нужен вывод только части операций, выделите их до запуска.
2. Выберите программы или режим выбранных операций, проверьте сообщения о диаметрах и MCS.
3. Назначьте посты, затем выберите папку назначения.
4. При необходимости задайте O-номера, BIN, вызовы подпрограмм, привязки и копию рядом с проектом.
5. Нажмите «Вывести», проверьте список заменяемых файлов и результат сохранения.

## Настройки и файлы

Основной INI — `NX_Postprocess_To_Machine.ini` рядом с журналом. Он содержит посты, папки станков, расширения и параметры вывода. Относительные пути считаются от папки INI. Самих постпроцессоров в комплекте нет.

Последняя ручная папка и выбор копии у проекта запоминаются в `%LOCALAPPDATA%\NX_Postprocess_To_Machine\LastChoice.ini`. Подготовка УП/BIN использует временную рабочую папку, которая удаляется при завершении. Постоянные резервные копии выходных УП и BIN не создаются. При сбое во время публикации часть результатов уже может быть сохранена; сообщение перечисляет такие файлы.

«Копия у проекта» означает копию выходных УП/BIN, а не сохранение самого PRT. Подробнее: [настройки постпроцессирования](configuration.md#постпроцессирование).
