# Зеркальная копия CAM-проекта — тест

**Русский** | [English](en/mirror-project.md)

Скрипт: [`NX_Mirror_Project.py`](../scripts/NX_Mirror_Project.py). Версия: **V1.03**.

## Изменения последней версии

**V1.03 · 14.11.2026** — заменён вызов Python `Cambnd.AskBoundaryData`, на котором V1.02 завершалась ошибкой доступа к памяти при чтении границы Blank. Параметры границы теперь читаются через `UF_CAMBND_ask_boundary_data` с указателем полного размера и явно выделенной структурой C. Дескрипторы границ больше не передаются между C API и Python-обёрткой.

Возвращённые массивы освобождаются отдельно от принадлежащих NX дескрипторов; поле `app_data` не разыменовывается. Проверка автоматически определяемой плоскости границы сохранена. Ошибки чтения не пропускаются. В отчёте указан номер границы и этап чтения её параметров или элементов. Выбор плоскости щелчком сохранён.

**Это тестовая версия. Полный успешный проход в NX / Designcenter 2606 ещё не подтверждён. Числовые направления и координаты внутри настроек операций пока остаются без преобразования.**

## Порядок работы

1. Откройте простую тестовую деталь без компонентов. Она должна быть полностью загружена, быть рабочей и отображаемой деталью и иметь обычный файл `.prt` на диске.
2. Сохраните её штатной командой NX. При признаке несохранённых изменений скрипт остановится; сам исходник он не сохраняет.
3. Запустите **Tools → Journal → Play** и выберите скрипт. В апдейтере: **«Зеркальная копия CAM-проекта — тест» V1.03**.
4. Щёлкните по **плоской грани** детали или **базовой плоскости** в окне NX. Плоскость может быть наклонной. Используется положение самой поверхности, а не точка курсора; знак нормали не влияет на отражение. Неплоские поверхности и объекты другого компонента не принимаются. Отмена выбора завершает скрипт без создания копии.
5. После выбора плоскости рядом с исходником создаётся первый свободный файл вида `имя_MIRROR_TEST_001.prt`. Существующие файлы не заменяются.
6. Прочитайте отчёт и передайте его через **«Копировать всё»**. Если проверки пройдены, осмотрите тела, MCS и геометрию каждой операции. Затем сохраните открытую тестовую копию штатной командой NX и рассчитайте операции заново.

**До ручного сохранения отражённый результат находится только в открытой сессии NX. На диске остаётся первоначальная копия исходного PRT.**

## Что делает скрипт

- Побайтово копирует сохранённый PRT, проверяет контрольные суммы и открывает отдельную копию. CAM исходника не обрабатывается.
- В копии читает операции, MCS/RCS, ссылки геометрии Part, Blank, Check, Trim, Cut Area, Wall и Drive, включая элементы коллекторов и поддерживаемые границы.
- Применяет отражение к телам и поддерживаемой ссылочной геометрии через преобразование модельных родителей. Идентификаторы тел, граней и рёбер должны сохраниться; иначе тест считается не пройденным.
- Создаёт перенесённые MCS/RCS. Оси X и Z отражаются, а ось Y достраивается для правой системы координат. Локальные определения заменяются; у корневой геометрии при необходимости задаётся собственная система. Наследование проверяется.
- Удаляет рассчитанные траектории в копии. Не создаёт зеркальные CAM-операции, не генерирует траектории и не выполняет постпроцессирование.
- Проверяет точные ориентированные габариты объектов в системе выбранной плоскости, идентификаторы геометрии, доступные выбранные CAM-ссылки, состав и геометрических родителей операций, отсутствие траекторий и положения MCS/RCS. В конце проверяет контрольную сумму исходного файла и его признак изменения.
- При исключении после установки метки Undo пытается откатить изменения в копии и показывает этап, ошибку и результат отката. Если откат не удался, копию следует закрыть без сохранения.

## Ограничения первого теста

- Поддерживаются только классы операций `VolumeBased25DMillingOperation`, `SurfaceContour`, `PlanarMilling`, `TpMultiAxisDeburring`. Существующие зеркальные операции отклоняются.
- Разрешена простая локальная история: DATUM_CSYS, DATUM_PLANE, DATUM_AXIS, SKETCH, EXTRUDE, BLEND, Tooling Box, FSET, BREP, BLOCK, CYLINDER, CONE, SPHERE, IMPORTED_BODY, IMPORT. Другие типы и обнаруженные внешние родители останавливают тест до преобразования.
- Компоненты, границы с заданной вручную плоскостью, неассоциативные границы без геометрических ссылок и обнаруженные пользовательские стартовые/предсверлильные точки пока не поддерживаются.
- Числовые пространственные параметры операций не отражаются. Отчёт перечисляет обнаруженные локальные ненулевые 3D-параметры для проверки; это не полный перечень всех пространственных настроек. Подачи, припуски и стратегии скрипт не редактирует.
- Сохранение ссылок и габаритов не доказывает правильность обработки. До применения к рабочему проекту необходимо проверить выбранные зоны, направления, заходы/отходы и заново рассчитанные траектории.
- Скрипт рассчитан на Windows и доступные в установленном NX библиотеки UF. Недоступные разделы геометрии с кодом 1345005 перечисляются как непроверенные. Их содержимое не подтверждено; успешные проверки доступных ссылок не означают полной проверки всех зон. Остальные ошибки API или неудачное преобразование останавливают тест.

## Файлы и проверки

Скрипт создаёт только запрошенную копию PRT. Не пишет отчётов, INI, журналов, архивов, временных файлов или `.dlx`. Не вызывает Save, SaveAs или SaveAll. Отчёт формируется в памяти; в нём есть имена, координаты и путь тестовой копии. Ничего автоматически не отправляется. После неудачного теста созданная копия PRT может оставаться на диске.

Пройдены 39 проверок вне NX. Шесть проверок используют отдельно скомпилированную C-библиотеку: размер и смещения полей структуры, 64-битные указатели, освобождение только массивов, чтение границы Blank и её геометрических ссылок, остановка при ошибке и недопустимой плоскости. Сохранены проверки выбора плоскости, копирования и отката; добавлена проверка отката при исключении доступа к памяти. Эти тесты не выполняют ядро NX. В V1.02 пользователь подтвердил выбор плоскости и откат после ошибки чтения границы; полный проход V1.03 в NX ещё предстоит проверить.
