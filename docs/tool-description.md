# Описания инструментов

Скрипт: [NX_Tool_D_To_Description.cs](../scripts/NX_Tool_D_To_Description.cs). [Все скрипты](../README.md#скрипты).

Заполняет General Description и Cutter Description инструмента по фактическим параметрам CAM.

## Возможности

- При каждом запуске предлагает два варианта: полный `⌀4_T4_H4_D4` или только диаметр `⌀4`.
- В полном варианте T берётся из Tool Number, H — из Adjust Register, D — из Cutcom Register.
- Если Cutcom Register отсутствует у этого инструмента, часть D пропускается; существующее значение 0 сохраняется как D0.
- Диаметр берётся из настроек инструмента, а не из его имени; дробные значения выводятся без лишних нулей.
- Обрабатываются инструменты текущей рабочей детали типов Mill, Drill, Barrel, Tcutter и MillForm. Выделение в навигаторе не ограничивает обработку.
- Неподдерживаемые типы и неположительный диаметр пропускаются. Уже совпадающие описания не переписываются.
- После записи проверяются оба поля и неизменность диаметра и номеров T/H/D.
- Ошибка отдельного инструмента отменяет его изменение; общая ошибка обновления вызывает попытку отмены всего запуска. В NX создаётся общая точка Undo.

## Как пользоваться

1. Откройте рабочий CAM-проект и запустите журнал.
2. Выберите полный вариант либо только диаметр. «Отмена» завершает работу без изменений.
3. Посмотрите Description в навигаторе инструментов и сохраните PRT.

Отдельного сообщения об успешном завершении нет; сообщения появляются при ошибках. Имена, геометрия и номера инструментов не изменяются, траектории не пересчитываются. INI и другие файлы не создаются; PRT автоматически не сохраняется.
