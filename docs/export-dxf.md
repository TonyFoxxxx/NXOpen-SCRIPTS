# Экспорт текущего вида в DXF

Скрипт: [NX_Export_Current_View_To_DXF.cs](../scripts/NX_Export_Current_View_To_DXF.cs). [Все скрипты](../README.md#скрипты).

Создаёт ортогональную 2D-проекцию модели в текущей ориентации вида и масштабе 1:1.

## Режимы

| Режим | Что попадает в DXF |
| --- | --- |
| Все видимые рёбра | Видимые рёбра модели, включая отверстия, уступы и карманы. |
| Только внешний контур модели | Внешний контур без отверстий и внутренних рёбер. |
| Только выбранные кривые | Рёбра и кривые, выделенные перед запуском. Режим появляется при таком выделении. |

## Возможности

- Использование текущего ракурса и видимых объектов модели.
- Сохранение предварительного выбора рёбер/кривых до открытия диалогов.
- Ввод имени с предложенным именем проекта и автоматическим расширением DXF.
- Вывод через штатный переводчик NX и его файл настроек `dxfdwg.def`.
- Фоновый перевод: журнал возвращает управление, а результат обрабатывается фоновой задачей NX.
- Очистка созданной для экспорта геометрии, служебного вида и листа.
- Возврат к модели в режиме Fully Shaded с прежним состоянием Face Edges.
- Проверка выходного DXF и обработка двух штатных журналов переводчика; предупреждения об очистке могут показываться при следующем запуске.

## Как пользоваться

1. Откройте сохранённый PRT, выставьте нужный ракурс и видимость модели.
2. Для третьего режима предварительно выделите рёбра или кривые.
3. Запустите журнал, выберите режим, затем введите имя файла.
4. Дождитесь завершения фоновой задачи NX и проверьте созданный DXF.

## Настройки и результат

Результат: `<папка отображаемого PRT>\<имя>.dxf`. Личного INI нет; используется штатная конфигурация переводчика DXF/DWG из установки NX. Если её не удалось найти, экспорт останавливается.

PRT не сохраняется. Скрипт не создаёт собственные отчёты и папки, но штатный переводчик NX использует свои служебные файлы. Старый DXF может быть восстановлен при ошибке до запуска фонового перевода; после запуска его результат контролирует фоновая задача NX.

Неоднозначный внешний контур и неподдерживаемая геометрия вызывают ошибку. Для одного контура действует ограничение используемого метода — не более 402 сегментов.
