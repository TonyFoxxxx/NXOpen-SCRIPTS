# Карта наладки

**Русский** | [English](en/setup-card.md)

Скрипт: [NX_Setup_Prototype.py](../scripts/NX_Setup_Prototype.py). [Все скрипты](../README.md#скрипты).

Создаёт один автономный HTML с картами выбранных установов, таблицами CAM и встроенными изображениями. Готовую карту можно редактировать в браузере, сохранять и печатать.

## Формирование карты в NX

- Выбор одного или нескольких установов в собственном дереве Program Order. Одна выбранная папка включает все свои операции и вложенные папки; одновременно выбрать родителя и его потомка нельзя. Предварительное выделение в навигаторе NX не влияет на выбор установов; оно используется только опцией Zmin в именах.
- Название установа, ориентация видов и источник IPW определяются по MCS первой операции выбранной папки.
- Для каждого установа отдельно выбираются видимые компоненты детали и оснастки. Выбор сразу показывается в NX; после окна выбора и съёмки восстанавливается исходная видимость.
- Создаются вид сверху, вид сбоку и изометрия относительно MCS. Каждый вид имеет варианты с IPW и без IPW с одинаковой камерой.
- На изображениях показаны оси X/Y/Z, привязанные к началу MCS. Геометрия вписывается с полями.
- Собираются инструменты каждого установа и общий каталог инструментов проекта. Повторяющиеся номера T вызывают предупреждение и отмечаются в карте.
- На первом листе размещается общий каталог инструментов. При включении галочки в стартовом меню добавляется вращаемая 3D-модель из видимой геометрии проекта в исходном ракурсе NX. Изображения и геометрия модели встроены в HTML.
- Отображаются этап и процент выполнения. При неполном создании установов предыдущий готовый HTML сохраняется.

### Запоминание выбора

При повторном запуске первое меню восстанавливает последние подтверждённые настройки текущего пользователя Windows. Выбор папок установов и компонентов относится к конкретному PRT; сохранённые настройки другого пользователя не подставляются. Оба меню по-прежнему показываются для проверки и изменения выбора.

Нажатие «Далее» сохраняет настройки первого меню и выбранные папки. Нажатие «Создать карту» сохраняет наборы компонентов каждого установа. Отмена или закрытие окна не записывает его неподтверждённые изменения; уже подтверждённый предыдущий этап остаётся сохранённым. «Как в NX» заменяет выбор компонентов текущей видимостью в NX.

Намеренно пустой набор компонентов также запоминается. Ответ «Нет» на вопрос «Добавить компоненты сборки для отображения?» не стирает прежний выбор. Удалённые, недоступные или неоднозначно сопоставленные папки и компоненты не отмечаются автоматически. Ошибки чтения или записи настроек показываются предупреждением и не запрещают формирование карты.

### Модель первого листа

Галочка «Создать фасетную 3D-модель на первом листе» при первом запуске снята; затем восстанавливается последний подтверждённый выбор пользователя. Когда она снята, текущий вид NX вписывается в окно без изменения ориентации, снимается и встраивается в первый лист. Камера и видимость восстанавливаются после съёмки, в том числе при ошибке. Временный PNG создаётся в существующей папке подготовки карты и удаляется сразу после встраивания.

При включении галочки справа появляется коэффициент, а ниже — лимит треугольников. Чем меньше коэффициент, тем грубее сетка и обычно меньше файл HTML. Число треугольников зависит от геометрии и не задаётся умножением лимита на коэффициент. Коэффициент не меняет размеры детали, IPW и виды установов.

Лимит по умолчанию — 500 000 треугольников на всю модель, включая повторные компоненты. Можно ввести другое целое число от 1 до 2 147 483 647, с пробелами или без них. Фактическая возможность построить и открыть большую сетку зависит от ресурсов NX и браузера. Коэффициент управляет фасетизацией твёрдых и листовых тел; уже готовые фасетные тела NX читаются с их существующей сеткой. Подтверждённые параметры сохраняются в настройках пользователя.

### Подготовка перед созданием карты

При первом запуске все три галочки сняты; затем восстанавливается последний подтверждённый выбор пользователя. Они меняют данные в текущем CAM-проекте, поэтому перед нажатием «Далее» проверьте их состояние. Карта формируется уже с обновлёнными именами.

| Опция | Действие |
| --- | --- |
| Нумеровать операции | В каждой выбранной папке заново нумерует все её операции, включая вложенные папки, в порядке Program Order. До 99 операций — `01_`, `02_`…; от 100 — `001_`, `002_`… Старые начальные номера заменяются. Без галочки не меняются. |
| Добавить параметры инструмента в описание (description) | Записывает оба поля General Description и Cutter Description для поддерживаемых инструментов всей текущей детали, включая неиспользуемые. Формат — `⌀6` либо `⌀6_T2_H3_D4`. D добавляется только при наличии параметра; читаемый ноль остаётся `D0`. Диаметр, T, H и D сами не меняются. |
| Добавить Zmin к именам операций | Использует выделение, сохранённое до открытия меню. Если операций не выделено и выделение полностью пустое — все операции проекта. Конечный числовой суффикс `_Z…` заменяется, например `MILL_Z-3.125`. Выделение одних папок или ошибка чтения выделения не разрешает переименовать весь проект. |

Галочки управляются мышью и пробелом; двойное нажатие на подпись переключает состояние один раз. Варианты Description появляются прямо в этом окне, без дополнительного диалога.

Поддерживаемые семейства инструментов: Mill, Drill, Barrel, Tcutter и MillForm с доступным положительным диаметром. Для остальных Description остаётся прежним. Ошибка отдельного инструмента отменяет его частичную запись; остальные обрабатываются. Недоступные/устаревшие траектории и конфликтующие имена Zmin пропускаются с пояснением в результате NX. Конфликт нумерации или общая ошибка подготовки останавливает создание карты и отменяет подготовку. Пояснения не добавляются в HTML.

## Данные операций и инструментов

Таблица операций сохраняет вложенность программных папок и содержит:

| Столбец | Данные |
| --- | --- |
| Операция | Имя и признак состояния траектории: рассчитана, отсутствует, требует пересчёта, подавлена или состояние недоступно. |
| Zmin | Минимум рассчитанной траектории по фактической оси инструмента, относительно начала MCS операции, в единицах CAM-детали. |
| Смена инструмента | Отметка перехода на другой инструмент. |
| Инструмент / T | Название и номер инструмента. |
| D | Cutcom register конкретной операции. Столбец расположен сразу после T и заполняется, только если этот номер инструмента использует во всём CAM-проекте два или более разных D. |
| Время | Время траектории; для групп — сумма времени активных траекторий. |
| Подача / обороты | Параметры обработки из CAM. |
| Припуск на стенки / пол | Параметры припуска, если доступны для операции. |
| СКС | MCS операции. |

В общем списке инструмента и списках установов столбец D содержит один и тот же полный набор используемых Cutcom register для номера T во всём CAM-проекте, без повторений и по возрастанию: `D5 / D12`. Учитываются операции вне выбранных установов и подавленные операции. Один инструмент не разбивается на несколько строк из-за разных D.

Значение операции читается из её параметров; оно может отличаться от Cutcom register самого инструмента и от T. Неиспользуемый регистр из параметров инструмента не добавляется к списку фактически прочитанных регистров операций. Только если ни один регистр операции прочитать не удалось, список инструмента использует доступное значение самого инструмента; при отсутствии данных показывается `—`. D не подменяется номером T.

Условие заполнения D в операциях проверяется по номеру T во всём CAM-проекте. При двух или более разных регистрах каждая операция показывает свой D, включая D = T и строки без отметки смены инструмента. При одном регистре ячейка операции пустая, даже если он отличается от T; в списке инструмента этот регистр отображается.

У инструментов выводятся доступные сведения о вылете H, режущей длине L и обниженной части HL. В карте есть расшифровка этих обозначений. Время траектории не включает все дополнительные затраты станка.

Столбец Zmin и необязательное переименование используют общий алгоритм [отдельного журнала Zmin](zmin.md) V1.04. Для обычных движений это `dot(P - O, unit(ToolAxis))` в сохранённых CL-точках; фактический вектор инструмента читается и для Three, и для Five. Для поворотной обработки начало MCS должно лежать на оси вращения детали. На дугах и винтовых движениях с постоянной осью учитываются внутренние экстремумы; изменение оси на дуге без данных интерполяции и составные пути не поддерживаются. Это не расчёт перемещений станка после постпроцессирования.

Для поддерживаемого центрования `Drill` / `Drill,Csink` конечный Z вычисляется по локальному FBM `DEPTH` до вершины. Для сквозных `STEP1HOLE` / `STEP2HOLE` учитываются полная локальная глубина операции, смещение дна и длина стандартной конической вершины — как для `SYS_CL_TIP` с выключенным `IgnoreToolTip`, так и для `SYS_CL_SHOULDER` с включённым. Положение отверстия и его ось сопоставляются с траекторией с допуском на малое округление координат FBM; соответствие должно быть однозначным. Глубина общего элемента модели, включая `DEPTH_1`, и старое имя операции источниками глубины не служат. Требуются стандартные настройки, перечисленные в [ограничениях машинных циклов](zmin.md#центрование-и-сверление).

Если глубина хотя бы одной точки Cycle не определена, Zmin всей операции остаётся пустым; частичный минимум и подставной Z0 не выводятся. При включённой опции переименования суффикс такой операции не обновляется. Добавление или замена суффикса Zmin выполняется только при включении этой опции в стартовом меню; тогда причины пропуска переименования показываются в результате NX.

## Редактирование в браузере

- Заполнение разработчика, названия детали, установа, даты, заготовки и примечания.
- Ввод привязок X/Y/Z вручную или выбор готовых формулировок.
- Автоматический рост примечания по содержимому без уменьшения его шрифта. Высоту также можно менять за нижнюю границу; она сохраняется в карте.
- Переход к нужному установу через список в верхней панели.
- Сворачивание Carrier нажатием на увеличенную стрелку перед названием: в списке остаётся заголовок, а все инструменты и вложенные группы скрываются. Повторное нажатие раскрывает группу. Стрелка плавно поворачивается за 160 мс: вниз при раскрытии и вправо при сворачивании. Обновляется только соответствующий список инструмента.
- Отдельный блок «Инструмент» содержит только инструменты, расположенные вне Carrier. Его стрелка скрывает или показывает только эти строки, не меняя состояния Carrier и их вложенных групп.
- Сворачивание независимо для списка каждого установа и общего каталога проекта и сохраняется вместе с HTML. При печати свёрнутый блок «Инструмент» или Carrier не выводится целиком, включая оставшийся на экране заголовок. «Исходный вид» раскрывает блоки соответствующего списка.
- Скрытие отдельных столбцов операций, ручное изменение масштаба таблиц и ширины столбцов. «Автоширина» распределяет ширину столбцов без изменения шрифта. Ползунки задают размер текста; автоматического подбора по длине текста и запаса на два пробела нет. Компоновка блока таблицы целиком в доступной области сохраняется.
- Галочка «Переносить названия операций» управляет только названием операции: без неё текст остаётся в одной строке с многоточием при нехватке места, с ней переносится. Остальные значения во всех таблицах операций и инструмента остаются однострочными, без переноса и многоточий; не поместившийся текст обрезается по границе ячейки. Для его размещения измените ширину столбца или масштаб; настройки сохраняются в HTML.
- Перенос выбранных операций на первый лист установа и обратно кнопками или перетаскиванием. Есть отключаемый лимит 25 операций на первом листе; размещение также ограничено свободным местом.
- Автоматическое разбиение операций на листы, повторение заголовков групп и сквозная нумерация страниц.
- Переключение изображения между IPW и NO IPW щелчком; сдвиг, увеличение и возврат к масштабу 100% или центру.
- Независимая настройка размера стрелок СКС, цвета и толщины их контура. Эти регуляторы не меняют масштаб таблиц.
- Двойное нажатие на название любого ползунка возвращает только его параметр к 100%, без выделения текста. Подсказка появляется при наведении на название. Нажатие на число процентов открывает ручной ввод: Enter или выход из поля применяет целый процент в пределах регулятора, Esc отменяет ввод.
- Добавление сетки ячеек изображений до 6 × 6 при наличии места, вставка своих картинок через Ctrl+V, удаление, перенос и обмен ячеек. Поддерживается выбор нескольких ячеек; добавление, удаление и перемещение входят в общую историю отмены.
- Изменение границ ячеек и высоты блока изображений; выравнивание ячеек.
- Вращение общей 3D-модели мышью, сдвиг с Shift, масштаб колесом, команды «Вписать» и «Исходный вид». Масштаб и размещение модели сохраняются; модель присутствует в печатном виде карты.
- При вращении или сдвиге модели положение таблицы инструментов и доступная ей область обновляются в реальном времени. Автоматический подбор шрифта не выполняется ни во время движения, ни после отпускания мыши; масштаб регулируется ползунком.
- «Исходный вид» над каждым листом восстанавливает исходные элементы, размеры, компоновку и настройки. Удалённые исходные картинки возвращаются, добавленные после создания ячейки убираются. На листе проекта восстанавливается первоначальный вид модели; на листе установа — также стрелки СКС, изображения и размещение операций. Сохраняются примечания, привязки, общие настройки столбцов и настройки других листов. Исходное состояние сохраняется внутри HTML; весь сброс можно отменить одним действием.
- «Отменить» в верхней панели, «Отменить действие» у установа или Ctrl+Z вне текстового поля отменяют последнее изменение карты. Можно последовательно отменить до 100 действий, включая удалённые картинки; сохранение не сбрасывает историю. В текстовом поле Ctrl+Z отменяет ввод. После закрытия или перезагрузки HTML история начинается заново.
- При открытии из NX карта сохраняется автоматически в свой исходный HTML, примерно через секунду после паузы в редактировании. Выбирать файл при первом сохранении не требуется. «Сохранить карту» и Ctrl+S позволяют записать правки сразу.
- При открытии HTML напрямую из папки остаётся прежний режим: «Сохранить карту» запрашивает исходный файл, если браузер поддерживает доступ к файлам; иначе скачивается HTML. При ошибке доступна кнопка «Скачать копию».
- «Печать» открывает печать браузера с листами A4. Через доступный в системе PDF-принтер можно сохранить PDF.

### Условия автосохранения

Карту нужно редактировать во вкладке, которую открыл скрипт, по адресу `http://127.0.0.1:<порт>/card/…/`. Помощник запускается автоматически отдельным процессом и работает, пока открыт запустивший его NX. Он выполняет только файловые операции, без NXOpen: обслуживание браузера не зависит от выполнения Python-потоков внутри NX после завершения журнала. Повторные запуски журнала используют тот же помощник.

Сначала используется существующий `python.exe` из окружения NX. Если его нет или он не запускается, скрипт определяет DLL уже загруженного Python NX и передаёт её штатному Windows PowerShell. Запускающая часть работает в памяти, а каталоги библиотек берутся из текущего окружения NX. Скрипт ничего не устанавливает, не ищет Python в PATH, не создаёт отдельный файл помощника, новые INI, журналы, резервные копии или другие служебные файлы. Политики Windows и PowerShell не меняются.

До открытия браузера проверяется настоящий HTTP-ответ. Если оба способа запуска недоступны, запуск запрещён системой или помощник не отвечает, готовый HTML автоматически открывается напрямую с обычным сохранением через браузер. В этом случае автосохранение без первого выбора файла недоступно; пояснение показывается в NX, не в HTML.

Путь результата не меняется: его хранит помощник в памяти, а страница не может передать произвольный путь для записи. Служебный ключ сеанса не включается в сохранённый HTML. После обновления с V2.38 редактируйте новую вкладку, которую откроет V2.39; старый помощник внутри NX останавливается.

Запросы принимаются только на loopback-адресе, от страницы того же источника и с её ключом. Проверка идентификатора и редакции не позволяет старой вкладке затереть сохранение другой вкладки или повторный экспорт NX. В случае конфликта автоматические попытки останавливаются: сохраните свои правки кнопкой «Скачать копию» перед перезагрузкой вкладки и объедините их с актуальной картой вручную.

После успешного нажатия «Сохранить карту» или Ctrl+S рядом с кнопкой на 3 секунды появляется зелёное подтверждение «Карта сохранена». Оно не сдвигает интерфейс. Уведомление появляется после подтверждённой записи HTML; отмена, ошибка и простая передача файла браузеру для скачивания не подтверждают сохранение. Автосохранение не показывает уведомлений.

Во время записи кнопка показывает «Сохранение…». При ошибке появляется «Повторить сохранение» и становится доступна «Скачать копию» — без всплывающих окон и жёлтых предупреждений. Черновик остаётся в браузере, насколько позволяет его хранилище; это не замена сохранённому HTML. При закрытии NX автосохранение прекращается; при следующем запуске журнала карта снова открывается через помощник. Уже сохранённый HTML остаётся автономным и пригодным для передачи и печати.

Перед закрытием вкладки, закрытием NX или повторным экспортом нажмите «Сохранить карту» и дождитесь завершения записи. Мгновенное закрытие до истечения задержки не гарантирует запись последнего изменения. Автосохранение пишет существующий файл без временной копии; при обычной ошибке записи восстанавливаются прежние байты из памяти, но защита от аварийного выключения питания не гарантируется. Размер одного сохраняемого HTML ограничен 256 МиБ; для большей карты остаётся скачивание копии.

## Повторное создание

Повторный запуск обновляет выбранные установы в существующем HTML. Невыбранные установы переносятся вместе с сохранённым оформлением; в них и в общем каталоге актуализируются только ячейки D по данным всего текущего CAM-проекта. Если выбрана общая папка, прежние отдельные записи её подпапок объединяются в неё.

Для обновления D сохранённая операция должна однозначно соответствовать операции NX по идентификатору, имени и T либо по уникальному сочетанию имени и T. Если соответствие неоднозначно или регистр прочитать не удалось, вместо предположения выводится `—`, когда для этого инструмента требуется отображение D. Изменённые вручную или устаревшие имена могут помешать сопоставлению; в таком случае заново сформируйте соответствующий установ.

У заново сформированных установов переносятся сохранённые примечания, их заголовки и высота, а также привязки X/Y/Z. Состояние сворачивания блока «Инструмент» и сохранившихся групп Carrier переносится при повторном выводе. Остальная компоновка выбранного установа формируется заново; сохранение всех ручных правок этой части не гарантируется.

## Как пользоваться

1. Откройте сохранённый CAM-проект как рабочую и отображаемую деталь. Подготовьте траектории и нужную геометрию IPW.
2. Запустите журнал, отметьте папки установов и проверьте предупреждения.
3. Выберите видимые компоненты для каждого установа и дождитесь создания карты.
4. После завершения откроются карта с автосохранением и папка результата; путь к папке копируется в буфер обмена.
5. Внесите пояснения в открытой вкладке, дождитесь сохранения и распечатайте. Оставляйте NX открытым на время редактирования.

## Настройки и результат

- `NX_Setup_Prototype.ini` рядом со скриптом: `[SetupCard] programmer` задаёт имя разработчика по умолчанию. Без значения поле остаётся пустым.
- `%APPDATA%\NX_Scripts\NX_Setup_Prototype.ini`: подтверждённые настройки первого меню текущего пользователя Windows. Этот файл отделён от INI с именем разработчика рядом со скриптом.
- `NX_Setup_Prototype.project.json` в папке PRT: один файл с выбранными папками установов и компонентами, раздельно для пользователей и файлов PRT в этой папке.
- Результат: `<папка PRT>\Карты Наладки\<имя проекта>\<имя проекта>.html`. Недопустимые для Windows символы в имени заменяются.
- Снимки и рабочие файлы используются при подготовке, затем удаляются; готовый документ содержит необходимые изображения внутри. Существующая единственная папка подготовки создаётся рядом с PRT под коротким именем `.nx_…`, без прежних вложенных папок `.capture/setup-…`. Если папка результата перенаправлена на другой том, подготовка остаётся на томе результата, чтобы замена готового HTML оставалась атомарной.
- Файловые операции Python, повторный экспорт, INI и автосохранение поддерживают расширенные пути Windows без изменения реестра и конечных имён. NX получает обычный путь к снимку либо существующий короткий путь 8.3. Пути всех снимков проверяются до построения модели и съёмки. Если уже сама папка PRT слишком длинная и коротких имён нет, создание останавливается с просьбой сохранить проект средствами NX в менее вложенной папке; предыдущий HTML остаётся нетронутым. Поддержка длинных путей Проводником и другими приложениями зависит от этих приложений.
- PRT автоматически не сохраняется, траектории не пересчитываются. После съёмки восстанавливается видимость, включается триада и выполняется вписывание вида NX.
- Для недоступной, отсутствующей, устаревшей или неподдерживаемой траектории Zmin остаётся пустым. При недоступном `ToolAxis` подстановка фиксированной оси MCS не выполняется. Перед использованием проверьте значения на известном контрольном проекте; выполнение новой версии в целевой NX / Designcenter требует контрольного запуска.

Пример INI и подробности: [настройки](configuration.md#карта-наладки).
