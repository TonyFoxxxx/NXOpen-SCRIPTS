# Открытие папки проекта

Скрипт: [NX_Open_Project_Folder.cs](../scripts/NX_Open_Project_Folder.cs). [Все скрипты](../README.md#скрипты).

Открывает в Проводнике папку PRT текущей рабочей детали. Если рабочей детали нет, использует отображаемую.

## Возможности и запуск

1. Откройте сохранённый проект в NX и запустите журнал.
2. Скрипт получает полный путь PRT, проверяет существование папки и открывает её через оболочку Windows.
3. Если проект не открыт, не имеет полного пути или папка недоступна, появляется пояснение.

INI, папки и файлы не создаются. Модель не изменяется и не сохраняется. Если в сборке рабочей сделана отдельная деталь, открывается папка именно этой рабочей детали.
