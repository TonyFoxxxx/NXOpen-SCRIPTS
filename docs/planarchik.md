## Изменения последней версии

**V1.01 · 05.11.2026.** Первая публикация в каталоге апдейтера. PlanarCHIK можно установить и затем обновлять под постоянным именем `PlanarCHIK.cs`.

Эта редакция включает вопрос «Добавить припуск?», ввод одного значения Stock для всех обрабатываемых элементов и единое обозначение версии в сообщениях. При публикации функциональность сохранена. Проверены каталог, версия, SHA-256, установка и обновление через код апдейтера. Запуск внутри NX / Designcenter здесь не выполнялся.

## Возможности

- Обрабатывает одну или несколько выбранных операций типа `PlanarMilling` (PLANAR_MILL).
- Задаёт **Tool Position = On** каждому элементу **Members / Item** во всех наборах **Part Boundaries** этих операций.
- По ответу **«Да»** на вопрос **«Добавить припуск?»** запрашивает одно числовое значение, включает **Custom Member Data → Stock** у каждого элемента и записывает этот припуск.
- По ответу **«Нет»** изменяет только Tool Position; существующие флажки и величины Stock сохраняются.
- Перегенерирует траектории обработанных операций и показывает количество операций, пропущенных неподходящих операций и обработанных элементов границ.
- Создаёт общую отметку отмены. При ошибке изменения или перегенерации пытается отменить изменения текущего запуска и сообщает результат отмены.

## Установка и запуск

1. В [апдейтере](updater.md) выберите источник GitHub и свою рабочую папку. Нажмите **«Проверить»**.
2. Отметьте **«PlanarCHIK — границы и припуск»** и нажмите **«Применить выбранное»**. Новый скрипт требует ручного выбора.
3. Откройте CAM-деталь с созданным CAM Setup в Manufacturing.
4. В **Operation Navigator** выделите нужные операции, при необходимости удерживая Ctrl или Shift. Выделение одной папки не обрабатывает её содержимое: выбирайте сами операции.
5. Запустите установленный `PlanarCHIK.cs` через **Инструменты → Журнал → Воспроизвести / Tools → Journal → Play** или свою кнопку NX.
6. Ответьте на вопрос о припуске. При ответе «Да» введите Stock и подтвердите ввод. Отмена числового ввода завершает запуск до изменения операций.
7. Прочитайте итоговое сообщение и проверьте изменённые границы и траектории.

Кнопку NX создают один раз и связывают с установленным `PlanarCHIK.cs`. Апдейтер сохраняет это имя при следующих обновлениях; сам кнопку не создаёт. См. [настройку кнопок](installation.md#кнопки).

## Припуск и настройки

Значение вводится в единицах **рабочей детали**: `mm` для миллиметров или `in` для дюймов. Единица показана в запросе. Одно значение применяется ко всем обработанным элементам всех выбранных PLANAR_MILL. Ввод допускает конечное числовое значение; исходное значение при каждом запуске — 0.

По умолчанию `REGENERATE_TOOLPATH = true`: после изменения границ траектории пересчитываются. Это константа в исходнике, отдельного окна настройки нет.

Скрипт не использует INI, не сохраняет введённый припуск между запусками и не создаёт файлы, отчёты или журналы. Изменяются объекты CAM в открытой рабочей детали; сохранение PRT выполняется обычным способом в NX.

## Ограничения и сообщения

- Другие типы выбранных CAM-операций пропускаются. Если PLANAR_MILL не выбраны, скрипт сообщает об этом и завершает работу.
- Скрипт работает с уже существующими элементами Part Boundaries; новые границы не создаёт.
- Если открыто другое окно ввода NX, закройте его и запустите скрипт снова.
- Окна сообщений скрипта имеют заголовок **PlanarCHIK — V1.01**. Заголовок встроенного числового ввода `UFUi.GetInputDoubles` задаёт NX: скрипт показывает название и версию в строке запроса. Заголовок системного окна ошибки запуска журнала также задаёт NX; начальные сообщения об отсутствии CAM Setup или выделенных операций содержат название и версию в тексте.
- Проверки апдейтера не проверяют выполнение NXOpen. Совместимость с конкретной сборкой и результат обработки нужно проверить в NX / Designcenter.
