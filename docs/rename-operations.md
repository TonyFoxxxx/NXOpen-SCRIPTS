# Переименование операций

Скрипт: [NX_Rename_Operations_In_Selected_Folder.cs](../scripts/NX_Rename_Operations_In_Selected_Folder.cs). [Все скрипты](../README.md#скрипты).

Назначает операциям общее базовое имя с последовательными суффиксами: например, `ROUGH_1`, `ROUGH_2`, `ROUGH_3`.

## Возможности

- Обработка непосредственно вложенных операций одной выбранной папки. Операции её подпапок автоматически не включаются.
- Обработка одной или нескольких отдельно выделенных операций. Смешанное выделение операций и папок отклоняется.
- Порядок нумерации соответствует дереву Operation Navigator; порядок щелчков и выделения через Shift/Ctrl на него не влияет.
- Проверка занятых имён во всём CAM-проекте, включая операции, инструменты, геометрию и другие CAM-группы. Занятые номера пропускаются.
- Предварительная подготовка всех имён до переименования и отмена изменений текущего запуска при ошибке NX.
- Окно результата с количеством переименованных операций и назначенными именами; одна видимая точка отмены.

## Как пользоваться

1. В рабочем CAM-проекте выберите одну папку либо нужные операции.
2. Запустите журнал и введите базовое имя без порядкового суффикса.
3. Проверьте результат. При необходимости используйте отмену NX; для сохранения имён сохраните PRT.

INI и выходные файлы не создаются. Траектории не пересчитываются. Все выбранные операции должны принадлежать рабочей детали; если положение выделенных операций в дереве не определено, переименование останавливается.
