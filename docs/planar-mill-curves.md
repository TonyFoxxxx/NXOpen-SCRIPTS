# Кривые для PLANAR_MILL

**Русский** | [English](en/planar-mill-curves.md)

## Изменения последней версии

**V1 · 12.11.2026** — первый выпуск. Добавление геометрии надписи, эскиза или выбранных кривых в существующую PLANAR_MILL. Связанные цепочки становятся отдельными открытыми или замкнутыми границами. Для новых элементов назначаются Tool Position **On** и нулевой Stock.

Исходник: [NX_PlanarMill_Select_Curves.cs](../scripts/NX_PlanarMill_Select_Curves.cs).

## Порядок работы

1. Подготовьте плоскую надпись однолинейным шрифтом или кривые эскиза. Для Text отключите создание ограничивающей рамки.
2. Создайте и настройте операцию **PLANAR_MILL**: инструмент, способ обработки по профилю, глубину, подходы и отходы. Закройте её окно редактирования.
3. Выделите **одну** операцию PLANAR_MILL в навигаторе операций.
4. Запустите журнал через **Инструменты → Журнал → Воспроизвести**, выбрав `NX_PlanarMill_Select_Curves.cs`, либо используйте настроенную кнопку.
5. В окне выбора укажите целый элемент **Text** или **Sketch** в навигаторе модели. Для отдельных кривых можно использовать множественный выбор и рамку в графическом окне. Подтвердите выбор.
6. Скрипт покажет число добавленных кривых и границ. Просмотрите границы в операции и рассчитайте траекторию штатной командой NX.

При выборе целого эскиза добавляются все его рабочие кривые. Вспомогательная геометрия пропускается. При выборе отдельных кривых добавляются именно выбранные объекты; чтобы обработать надпись целиком, выбирайте элемент Text.

## Работа с границами

- Связанные по концам кривые сортируются в цепочки. Раздельные буквы и штрихи не соединяются через зазоры.
- В местах разветвления создаются отдельные цепочки. Пересечения в середине кривых не разрезают исходную геометрию.
- Замкнутые контуры, включая окружность или замкнутый сплайн из одной кривой, сохраняются замкнутыми.
- Добавляются локальные **Part Boundary** выбранной операции. Уже существующие локальные границы сохраняются.
- Повторный выбор одного объекта исключается по его NX Tag. Уже назначенные этой операции объекты пропускаются. Совпадающие геометрически кривые с разными Tag автоматически не удаляются и не объединяются.
- Новые границы и их элементы получают Stock = 0; новые элементы — Tool Position = On. Другие параметры операции скрипт не назначает.
- Плоскость определяется по геометрии выбранных кривых. Если все точки лежат на одной прямой, используется допустимая плоскость с ориентацией относительно WCS: перед запуском выровняйте WCS с требуемой плоскостью гравировки.

Скрипт не превращает контурный TrueType-текст в однолинейный. Если исходная надпись имеет двойные контуры, будут выбраны эти контуры. Он также не отменяет настроенную в операции коррекцию инструмента и не подбирает глубину гравировки.

## Ограничения и отмена

- Поддерживаются отрезки, дуги, окружности, эллипсы и сплайны рабочей детали, лежащие в одной плоскости.
- Компоненты сборки, рёбра тел, Drafting Note и неплоские надписи в V1 не поддерживаются.
- Если операция наследует существующие границы родительской геометрии, запуск останавливается до изменения. Сначала задайте локальные границы именно этой операции штатными средствами NX.
- Для соединения концов и проверки плоскости используется допуск 0,000001 мм, пересчитанный в дюймы для дюймовой детали. Зазоры больше этого значения оставляют цепочки раздельными.
- Проверяется состав новых границ, их открытость, положение инструмента и припуск. При обнаруженной ошибке выполняется откат к отметке начала изменения.
- Успешный запуск отменяется одним **Ctrl+Z**.
- Траектория автоматически не рассчитывается. Скрипт не сохраняет PRT, не создаёт файлов, журналов, INI, копий кривых или новых CAM-операций.

## Проверки

Компиляция исходника с библиотеками Designcenter 2606. Алгоритмы цепочек и плоскостей проходят 21 сценарий: отдельные штрихи, разветвления, замкнутые петли, обратное направление кривых, зазоры, границы пространственных ячеек, наклонные плоскости и отказ для неплоской геометрии.

Полный интерактивный запуск в NX и расчёт полученной траектории пока не подтверждены: фоновый запуск NX в среде проверки завершается ошибкой до выполнения журнала. Проверка компиляции и автоматические тесты не заменяют этот этап.
